# Why

O Core App não chama o orquestrador contextual R; o bridge analítico existente injeta pesos operacionais. Falta fronteira autenticada para fatos curriculares e estado FSRS.

# What Changes

Adicionar produtor Java somente leitura e serviço shadow desligado por padrão; autenticar bytes entre processos; construir especialistas no R e reutilizar admissão, três políticas, rastro e laboratório. Preservar estados pessoais/científicos desconhecidos e ausência total de intervenção.

# Impact

Sem frontend, microsserviço, chaves operacionais, eventos operacionais novos, piloto, treinamento ou integração ao planejamento. Detalhamento e limites em `docs/architecture/CORE_LEARNING_SHADOW.md`.
